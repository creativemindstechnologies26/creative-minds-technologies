# Creative Minds Technologies Website

Responsive static website for Creative Minds Technologies. Built with HTML, CSS and vanilla JavaScript.

## Features
- Premium dark navy / blue corporate design
- Responsive desktop and mobile navigation
- Services, company overview, process and contact sections
- Featured portfolio grid linked to Karthik Sivashanmugam's public GitHub repositories
- Authentic screenshots from the AI Job Market Analyzer, AI Civilization Monitor and BRADD repositories
- CSS-based illustrative visuals for projects whose repositories do not currently include a product screenshot
- Clickable email and phone details
- Contact enquiry form that prepares an email in the visitor's email application (no form data is stored)

## Featured projects
- AI CEO — Corporate Strategy Decision System
- Real-Time AI Civilization Monitor
- BRADD — Voice-Driven AI Assistant
- AI Job Market Analyzer
- SmartDesk POS System
- Retail Profit Dashboard

Project details are based on public repository documentation. These are portfolio projects, not client case studies.
